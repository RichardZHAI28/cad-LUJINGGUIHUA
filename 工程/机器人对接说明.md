# UR / ELITE CS/ES 对接使用说明

## 打开与配置

首页三点示教：点击“1 原点 O → 2 X方向 → 3 XY平面”，在主界面按顺序将已标定 TCP 尖端移到对应工件点，停稳后点击“记录当前 TCP”；也可输入示教器基座坐标下的 X,Y,Z（mm）。O 是工件原点，O→第二点定义 X 正向，第三点在 Y 正侧定义 XY 平面，Z 正向按 X×Y 计算并在页面显示。点间距、共线检查失败时不会应用。核对后点击“计算并应用”，写入当前品牌的 frame；UR 使用旋转向量，ELITE 使用 XYZ 欧拉角，均为 rad。三点不改变 TCP 或枪姿态，不创建示教器中的命名坐标。未应用修改会阻止启动、导出。

“记录当前 TCP”只接收状态端口的数据，不下发脚本或运动命令，采两次稳定位置后转成 mm；配置 TCP 与控制器不一致、不同 TCP 或不同连接的点混用时拒绝应用。机器人移动请用示教器操作。三点示教是独立的工件定位，CAD 始终按世界坐标 WCS 读取；图纸 WCS 基准点映射到工件 O，默认 (0,0)。沿工件 Z 抬升的方向由第三点决定，请核对方向是否离开工件。

首页“输入文字 / 数字”生成的文字与 DXF 共用规划、预览、导出和启动流程，无需临时 DXF。使用所选实际字库文件，缺字不替换；可调字高、WCS 左下角位置、多行间距及主界面整体字号。单位固定 mm，CAD 单位换算倍率只影响 DXF。

双击根目录 start.bat，点击左侧“机器人设置…”。选择 UR 或 ELITE CS/ES。两家配置独立保存到 工程/robot_profiles.json，切换品牌不会复制坐标和姿态；保存后下次打开仍可使用。此次不支持 ELITE EC/EA 的 JBI 程序。

“坐标、运动与焊接”页设置：
- 用户坐标相对机器人基座：X,Y,Z 以 mm 输入，Rx,Ry,Rz 以 rad 输入。
- TCP 标定来源默认“沿用控制器已标定 TCP”，脚本不执行 set_tcp。仅选择“使用下方 TCP 参数”时覆盖控制器 TCP，平移单位 mm，姿态单位 rad。
- 姿态参考分三种：默认“保持程序启动时的 TCP 姿态”，在运行入口读取一次并保持；“基座坐标系姿态”使用输入的固定基座姿态；“用户坐标系姿态”会叠加用户坐标系旋转。UR 输入旋转向量，ELITE 输入 XYZ 欧拉角，均为 rad，两家姿态数值不可直接复用。
- 老配置缺少新增模式时，默认改为沿用控制器 TCP、保持启动姿态；原数值保留但不会自动应用。若要恢复以前的处理，需明确选择“使用下方 TCP 参数”和“用户坐标系姿态”，重新生成脚本。旧脚本不会自行更新。
- 空移/升降速度、加速度、标准 DO、起弧电平、起弧等待和终点保持起弧时间。
- 主界面的作业 Z、抬升量、焊接速度仍控制实际轨迹。

“通信与设备”页填写型号、控制器版本、IP、端口及合法程序名。型号和版本仅作记录，不会自动识别控制器能力。

默认全部坐标为占位零值，必须填写实际标定数据。默认不发送任何焊接 DO 指令，不会主动改变控制器当前 DO 状态；空跑应断开焊接能量。启用 DO 后才按配置电平执行起熄弧。本版只实现数字输出和等待，未加入焊机就绪、起弧成功、故障握手及气阀控制。

## 离线导出

点击“生成预览”会按当前图纸和参数重新生成轨迹及脚本。点击“导出脚本”保存到 输出结果，默认文件名分别为 xxx.ur.script 和 xxx.elite.script，内容均为对应控制器脚本。

导出包含：TCP 来源与姿态参考模式、用户坐标、运动单位换算、起熄弧（如启用）、每段结束的垂直抬升与高位转移。可在机器人配置窗口设置焊接圆滑半径；0 为精确停点。正数仅应用于焊道内部路点，起终点和空移/升降仍 r=0；离散点过密时半径会被限幅，控制器仍可能减速。若脚本过大请加大步长或分图处理；网络发送限制为 8 MB，未实现自动分包。

导出定义了配置程序名对应的函数，如 cad_job()。在示教器现有任务中加载脚本后，需要按该控制器的脚本节点方式调用 cad_job()。本版不生成 UR .urp 安装包或 ELITE 原生任务工程文件，也不会安装机器人端插件。ELITE 离线脚本加载方式需以当前系统版本手册为准，TCP 接口是本版直接执行的实现路径。

## 网络对接

UR 默认脚本端口 30002；ELITE CS/ES 默认 30001。按实际控制器网口设置 IP，电脑与机器人网络需互通，机器人需在允许外部脚本的远程控制模式。应用不自动上电、不自动解锁保护停止、不自动切远程模式。

- 测试连接：仅建立并关闭 TCP 连接，不发送运动或 I/O 命令。端口可连不代表品牌、程序语法和远程模式均正确。
- 主界面“启动”：重新生成当前轨迹，检查参数及远程就绪状态后直接发送完整 def...end 脚本，无验证勾选或二次确认。已有运行或暂停程序时不覆盖；状态未确认时不能再次启动，需先检查并停止。发送可能立即启动运动。
- 发送完成：仅代表 socket 已发送数据；随后运行状态以 Dashboard/状态流反馈为准，不代表已完成焊接工艺验证。
- 超时或断线：不自动重试，机器人可能已收到部分或全部程序，需先在示教器确认状态，不能盲目重发。

首次使用应先在对应仿真器核对脚本和轨迹，再按工作站条件验证。首点接近、TCP、负载、安全边界、可达性与避障尚需现场确认。主界面“停止”是网络程序停止，不是硬件急停。

## 主界面运行控制

- “启动”：运行新任务。运行参数和目标机器人在开始时取快照，后续设置变化不会改变该任务的暂停/停止目标。
- “暂停”：通过 Dashboard 暂停程序，读取控制器状态确认。启用焊接输出时记录暂停瞬间的 DO 状态，再通过 secondary 脚本熄弧并读回确认；空移阶段暂停不会被误认为起弧状态。
- ELITE 暂停后按钮显示“继续”：继续原任务，不重发轨迹。仅当暂停时原本起弧才恢复输出并等待配置的起弧等待时间。继续失败会再次尝试关闭起弧输出。
- UR 此次采用外部脚本直接运行，本版不开放 Dashboard 自动续跑，以免错误运行示教器加载的其他程序。暂停后可停止，再从头启动；在示教器自行继续不会自动恢复软件关闭的起弧输出。
- “停止”：发送程序停止并读取停止状态，启用焊接输出时尝试熄弧并确认输出。再次启动从头执行。停止请求不会自动抬升或回原点。
- 控制默认 Dashboard 29999、只读 Primary 30011；均可在“机器人设置 → 通信与设备”调整。状态查询与控制在后台运行，停止按钮在启动请求过程中仍可用。网络超时不自动重发轨迹，停止未确认时须检查示教器。
- 不自动上电、释放刹车、切换远程模式或解除安全停止。运行状态显示来自控制器反馈，网络连接断开不等于机器人已停。

ELISIM 2.16.1 已验证外部脚本启动、暂停、继续、停止，及模拟 DO15 的暂停熄弧、继续恢复、停止熄弧。测试后恢复原输出、POWER_OFF 和 LOCAL 模式。UR 控制接口依据 [官方 Dashboard 文档](https://www.universal-robots.com/manuals/EN/HTML/SW5_25/Content/prod-dashboard/Dashboard_table.htm)，此次没有 URSim 或 UR 实机联调。

## 实现与验证

robot_adapters.py：独立配置、两家脚本后处理、参数检查、单位和姿态表达、TCP 通信。
robot_window.py：品牌切换、配置保存、脚本预览/导出、连接测试、明确触发的发送执行；网络请求在后台线程运行。
test_robot_adapters.py：品牌差异、单位、电平、抬升顺序、配置隔离、通信失败不重试，以及本机 TCP 回环收包检查。

2026-10-27 已在用户提供的隔离 ELISIM 2.16.1 / CS612 中验证三种姿态模式的目标计算，并执行两段无焊接 DO 的虚拟运动，记录 9 个运动点、段间抬升/转移及姿态保持。UR 目前仅通过本机脚本测试。未做真机或焊机联调；仿真结果不能替代实际 TCP 标定及现场工艺验证。详情见根目录 诊断/TCP与界面修复报告.md。

## 焊接圆滑半径

在“机器人配置 / 通信 → 坐标、运动与焊接”中输入“焊接圆滑半径 mm”。UR 与 ELITE 分别保存，默认 0，旧配置文件自动补 0。正数写入焊道内部 movel 的 r，自动从 mm 换算为 m。

内部每点有效半径 = min(设定值, 前段长度×0.45, 后段长度×0.45)，以保守间距限制避免相邻过渡区重叠。重复点和接近原路折返处不圆滑，焊道起点、终点、升降、空移全部精确停点；闭合路径在起终点处仍保留停点。各段脚本注释记录设定半径与限幅点数。

圆滑半径是控制器过渡区参数，不是保证生成固定半径圆弧的几何倒圆。圆滑会偏离名义折线，二维预览及 CSV 仍为原始规划点，不显示控制器实际圆滑轨迹；目前没有对圆滑后的扫掠范围、越界、碰撞和焊缝覆盖重新仿真。请在对应控制器/仿真器验证实际轨迹，尤其是窄笔画、尖角和孔洞附近。参数改变后需重新预览、导出或发送，旧脚本不改变。

UR 官方过渡参数及重叠限制：https://www.universal-robots.com/manuals/EN/HTML/SW5_19/Content/prod-usr-man/software/PolyScope/content/BasicProgNodes/commandtab_way_blend_para.htm

## 屏幕尺寸与缩放

窗口初始大小按屏幕可用尺寸收缩，支持手动缩小和最大化。主界面的三个参数页及机器人设置、通信页支持纵向/横向滚动；鼠标滚轮仅作用于当前参数区。机器人窗口底部操作按钮分两行固定显示。参数内容超出时请使用滚动条。
