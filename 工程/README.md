## 三种加工模式

### 内外轮廓焊接

同时生成每个实体的外边界和所有内部孔洞边界。例如 O 字内外两圈均焊接。封闭轮廓之间熄弧、抬升、转移、下降再起弧。

### 实心排道填充

手动设置焊缝宽度、重叠率、填充方向和是否连续焊接。最大道间距 = 焊缝宽度 × (1−重叠率/100)。轨迹先按半个焊缝宽度内缩，避免理想焊缝越界。

- 从上向下：按用户 Y 从大到小排水平道，最后加边界收边道。
- 从左向右：按用户 X 从小到大排竖直道，最后加边界收边道。
- 由外向内：按道间距逐层内缩轮廓，先外层后内层。
- 由内向外：将内缩轮廓层次倒序，先内层后外层。

排道角度默认 0 度，可额外旋转排道坐标方向。内孔随轮廓偏置一起处理。

关闭连续焊接：每道独立起熄弧并抬升转移。开启连续焊接：平行排道使用往复走向，在保持层次顺序的前提下合并可连接的相邻焊道。连接线也保持起弧，并显示在预览中。仅当完整连接线位于内缩实体内部才连接；跨孔洞、实体外部或分离图形时仍断弧抬升，所以不保证整图只有一次起弧。

尖角、窄笔画和偏置残余可能无法完全覆盖，状态栏报告理想焊缝模型下的剩余面积。需调整焊缝宽度、重叠率或图形。实际熔宽仍需工艺验证。

### 中心线单道焊接

采用全边等距波前中线：对各条轮廓边按相同物理间距采样，利用欧氏距离 Voronoi 汇合线计算中线。上下端面与左右、斜向、曲线边界采用同一规则，端点保留在材料内部的汇合位置，不恢复到原始封口。剔除同边伪线和成对端角叉枝，保留内孔闭环；长直线拟合不得减少必要的收缩余量。实际交点处合并连续焊道，在不重复焊接的前提下减少起熄弧次数；多末端分支仍可能分道。所有替换线段留在实体内部。该方法是边界等距线的采样近似，不还原书法笔顺。

“中心线边界采样间距”默认 0.2 mm，数值越小越精细，每区域最多 30000 个边界采样点。对生成折线做不穿孔、不越界的简化，减少多余顶点。
新增“中心线短分支修剪 mm”，默认 0.5，设为 0 关闭。仅修剪交点处小于阈值的末端毛刺，不删独立短笔画。修剪也可能移除真实的短细节，需根据图形调整。不保证任意复杂字一笔完成；复杂交点、变宽笔画和尖角仍需核对，采样过粗可能丢失细节。

中心线模式限制保持有效：无孔洞、旋转包围矩形长宽比不超过 2，且紧凑度 4πA/P² 不低于 0.60 的区域按块状处理，禁止生成中心线。这包括实心圆、近圆形及部分实心方块。圆环和细长笔画仍可处理。此规则为保守几何判断，不是文字语义识别。

混合图纸只要有不适用区域就停止整次中心线生成，显示区域位置，并清空旧预览和可导出路径，不会静默跳过。请将实体分开处理或改用填充 / 内外轮廓。

## 坐标、抬升与 UR 导出

图纸点先扣除 CAD 基准点，再按比例缩放、旋转到用户坐标系。毫米图纸比例为 1，英寸为 25.4。字号倍率只影响文字，文字插入锚点不变。

手动输入作业 Z 和焊缝结束抬升量（必须大于 0，默认 20 mm）。过渡高度 = 作业 Z + 抬升量。例如作业 Z=5、抬升量=20，则过渡 Z=25 mm。每条连续焊道结束：熄弧→保持终点 XY 沿用户正 Z 抬升→保持过渡 Z 移动到下一段上方→下降到作业 Z→起弧。最后一段也抬升。

本工具生成离线模板，不连接机器人。现在通过主界面“机器人配置 / 通信”设置 UR 或 ELITE CS/ES 的实际用户坐标、TCP 和工具姿态。窗口的平移以 mm 输入，程序换算为 m；UR 姿态为旋转向量，ELITE 为 XYZ 欧拉角，均以 rad 输入。配置独立保存。详见 机器人对接说明.md。导出点经米换算和 pose_trans 转到基座系后使用 movel。作为 PolyScope 脚本文件节点加载后，需在后面的行脚本节点调用 cad_job()。

起熄弧示例使用 set_standard_digital_out，编号 0～7，高电平起弧、低电平熄弧。尚未实现焊机握手、预送气、收弧和故障处理，也未进行碰撞、可达性或奇异点检查。模板需先修改并在 URSim 和断开焊接能量条件下验证。过渡高度不是经过碰撞验证的避障路径，初次接近第一点也需现场规划。

## CAD 支持与限制

支持 TEXT/MTEXT、属性文字、闭合多段线、圆、椭圆、样条、块虚拟实体、HATCH/MPOLYGON 边界及 SOLID。未封闭路径提示并忽略，自交边界需在 CAD 修复。不支持自动将分散 LINE 拼成区域，未完整支持 REGION/ACIS。

区域按包含关系奇偶层级区分实体与孔洞，重复边界去重。嵌套独立实体若不是孔洞需分开处理。复杂 HATCH 岛屿样式未完整还原。字体使用系统字体生成轮廓，SHX、对齐、富文本与换行不能精确复现；精确原图请在 CAD 将文字转为多段线。曲线弦差只控制 CAD 几何曲线，不控制系统字体轮廓近似。

## 默认焊接顺序（用户坐标原点优先）

轨迹生成后，按用户坐标系实体位置排序，不采用 CAD 实体顺序或长度顺序。同排沿 X 正向完成后，再沿 Y 正向换排，即正象限从左到右、从下到上。各轴优先非负坐标，再处理负坐标；负坐标按距轴由近到远。排序不平移图形，也不要求机器人先运动至零点。

“焊接顺序行归并容差 mm”默认 5。基线差异在容差内，或实体竖向范围重叠达到较矮实体高度的一半时，归为同排，避免 Q 尾部、下伸笔画抢到同排左侧字母之前。各实体与固定行代表比较，不累积扩大行范围。高低行明显重叠或跨行大图形存在歧义时需拆图核对。按整个实体依次加工，不在不同字之间穿插同一高度的焊段。

中心线和轮廓的起点优先选取靠近用户原点的一端，闭合轮廓从距原点最近的位置起焊。填充模式只调整实体间顺序，实体内部保留从上向下、从左向右、由外向内或由内向外的方向设置及连续焊接路径，避免破坏工艺顺序。

预览绿点旁的数字即最终焊道编号；CSV、UR、ELITE 导出及网络发送使用同一序列。不会插入一条焊接移动到坐标零点；第一条轨迹仍经起点上方接近。更新后必须重新生成并导出脚本，旧文件顺序不会自动改变。
